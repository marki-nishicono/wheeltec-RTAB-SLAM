# 本次部署更新

按用户现场确认，频繁掉线由底盘电量不足引起，已停止进一步排查。

## 地图清理与删除

已停止地图服务后清空车端 wheeltec_slam_runtime/maps 下的旧数据库、保存副本、工作副本及旧会话状态，共 74 个文件；本机 results/control_recovery/map_snapshot.db 也已删除。随后启动全新 lab.db，保存列表为空。新地图将随有效传感器数据自动增长。

浏览器地图管理区新增“删除所选地图”。点击后显示所选地图名称供确认。后端仅允许删除合法 ID 对应的已保存数据库、视图缓存和元数据；地图切换过程中拒绝删除。当前工作副本独立保留，重复请求按请求 ID 去重。已使用临时测试地图完成实际 API 删除验证，验证后保存列表仍为空。

## 控制与显示

浏览器以 20 Hz 发送 WebSocket 控制指令，不等待上一条 HTTP 请求返回。控制和显示使用独立 SSH TCP 连接；车端控制状态采用独立锁。单一驾驶者、过期指令拒绝、急停作废旧指令与断线停车保留。旧 HTTP 行驶接口停用，旧页面需刷新。

相机预览和特征匹配画面默认关闭，用户打开后才传输。H.264 编码器按观看者计数启动，最后一个观看者离开后停止；相机采集及 SLAM 不由预览开关控制。相机无数据时视频连接有界退出。旧 JPEG/MJPEG 实时接口停用；SLAM 特征展示缓存仍在车端生成。

当前使用 x264 软件编码，未宣称硬件编码或 GPU 解码已经启用。此前实测相机约 29.6–29.7 fps，关闭预览时编码帧率及码率均为零。本次最后视频开关验证时相机采集为 0 fps，验证了观看者释放及关闭后零编码，未验证该时刻的正常视频画面。

## 验证与边界

29 项 Python 测试通过；WASD、投影和视频默认关闭/关闭后不自动重连的 JavaScript 测试通过。删除接口实际验证成功。用户驾驶期间曾观测连续指令最大间隔约 63 ms，也曾记录看门狗停车；不能据此宣称所有场景下无顿挫。按用户最新指示，不再继续掉线诊断。

Wi-Fi 节能已关闭，并在 NetworkManager 的 Cudy-A234 配置中持久化。ROS master、相机、传感器、建图服务分别管理，避免相机退出同时带走 ROS master。服务未设置开机自动启用运动。
